Beispiel mit 500 Punkten – Gleismesslatte V0.16
================================================

DATEIEN
  beispiel_500.txt        Leerzeichen getrennt, Aufbau P R H Z C, keine Kopfzeile
                          (= Standardeinstellung, Kommentarzeilen mit # beschreiben die Abschnitte)
  beispiel_500_csv.csv    dieselben Punkte als CSV: Semikolon, Dezimalkomma,
                          Aufbau P C R H Z, 3 Kopfzeilen
  beispiel_500_soll.csv   Sollwerte der Simulation je Paar (wahre Gleisachse,
                          Überhöhung, Spurweite) zum Nachprüfen

Die Punkte stammen aus einer simulierten Trasse (Gerade, Übergangsbögen,
Rechtsbogen R = 500 m, Linksbogen R = 400 m, Längsneigung 4 ‰) mit 0,7 mm
Messrauschen je Koordinate. Reflektorhöhe 0,130 m, Sollspurweite 1,458 m.

EINSTELLUNGEN
  beispiel_500.txt      : Achs-Codes = SOL,SOR   (sonst alles Standard)
  beispiel_500_csv.csv  : Achs-Codes = SOL,SOR, Aufbau = P C R H Z, Kopfzeilen = 3
  Paarbildung je nach Test "aufeinanderfolgend" oder "frei" (siehe unten)

ABSCHNITTE
  A  km 0,000–0,150  Gerade, u = 0, Code GML
  B  km 0,155–0,265  Übergang Rechtsbogen, Rampe 0 → 120 mm, Codes LI_GML / RE_GML,
                     jede 3. Lage in umgekehrter Punktreihenfolge gemessen
  C  km 0,270–0,415  Rechtsbogen R = 500 m, u = 120 mm, Codes GML01 / gml01 / GML02
  D  km 0,420–0,515  Übergang, Rampe 120 → 0 mm, Codes GML-L / GML-R in FREIER
                     Reihenfolge: erst alle linken Punkte vorwärts, dann alle
                     rechten rückwärts
  E  km 0,520–0,615  Gerade mit Bahnsteig, Achs-Codes SOL / SOR / sol / Sor direkt
                     auf SO gemessen (ohne Latte, keine Korrektur), Bahnsteigkante BSK
  F  km 0,620–0,755  Übergang + Linksbogen R = 400 m, u 0 → 90 mm LINKS hoch,
                     Codes L.GML / R.GML (Suffix mit Punkt)
  G  km 0,760–0,770  dichte Lattenlagen alle 0,5 m, Code GML
  H  km 0,775–0,800  Sonderfälle:
                     8001/8002  Spurweite 1,600 m – außerhalb der Toleranz
                     8003       GML-Punkt ohne Partner
                     8004       Achs-Code-Punkt SOL ohne Partner
                     8011/8012  Überhöhung 172 mm – Grenzwert 180 mm eingehalten
                     8013/8014  Überhöhung 195 mm rechts hoch – GRENZWERT ÜBERSCHRITTEN
                     8015/8016  Achs-Codes SOL/SOR, 188 mm links hoch – ÜBERSCHRITTEN
                     8005       fehlerhafte Zeile (Höhe fehlt)
                     8006       Werte mit Dezimalkomma, Code KS
                     8007       Code mit Leerzeichen "SIGNAL ASIG 12"
  sonstige           MAST (alle 25 m), FP (Festpunkte), BSK, KK (Kabelkanal) – unverändert

    "nicht gepaart" / "ohne Partner" für 4001–4038

    (alle Sollpaare gefunden)

    sind deshalb künstlich groß und nicht praxisrelevant.

    Achs-Code-Punkte (SOL/SOR) bleiben unverändert inkl. Code.
